# TurbineLog — Датасет показаний датчиков гидроагрегата

## Описание проекта

Данный датасет содержит синтетические временные ряды показаний датчиков гидроагрегата, предназначенные для разработки и тестирования системы интеллектуальной диагностики **TurbineLog**.

Основная задача — обнаружение аномалий (выбросов) в работе гидроагрегата с использованием методов машинного обучения, в частности алгоритма **Isolation Forest**.

Данные имитируют работу гидроагрегата в нормальном режиме с небольшими естественными колебаниями параметров, а также содержат специально внедрённые аномальные значения, моделирующие потенциальные отклонения в работе оборудования.

Датасет предназначен для экспериментов с алгоритмами обнаружения аномалий, анализа временных рядов и разработки интеллектуальных систем технической диагностики.

## Структура данных

Датасет содержит временную метку и шесть числовых параметров, характеризующих работу гидроагрегата.

| Столбец | Описание | Единица измерения |
|---|---|---|
| `Timestamp` | Дата и время измерения | YYYY-MM-DD HH:MM:SS |
| `Oil_Pressure_Bar` | Давление масла в системе смазки | бар |
| `Bearing_Temp_C` | Температура подшипника | °C |
| `Vibration_mm_s` | Уровень вибрации оборудования | мм/с |
| `RPM` | Частота вращения ротора | об/мин |
| `Active_Power_MW` | Активная мощность гидроагрегата | МВт |
| `Water_Flow_m3_h` | Расход воды через гидроагрегат | м³/ч |

## Описание нормального режима работы

Большая часть датасета представляет нормальную работу гидроагрегата.

В нормальном режиме используются следующие ориентировочные значения:

- **Давление масла:** около 4,2 бар.
- **Температура подшипника:** около 65,5 °C.
- **Вибрация:** около 1,8 мм/с.
- **Частота вращения:** около 3000 об/мин.
- **Активная мощность:** около 150,5 МВт.
- **Расход воды:** около 1200 м³/ч.

Для имитации реальных измерений в значения добавлены небольшие случайные колебания. Это позволяет проверять способность алгоритмов отличать естественные изменения параметров от действительно необычных показаний.

## Аномалии

В датасет специально добавлены несколько последовательных эпизодов отклонений. Они расположены близко друг к другу по времени, чтобы проверить способность модели обнаруживать несколько аномалий в рамках одного временного интервала.

| Временной интервал | Параметр | Описание отклонения |
|---|---|---|
| 22:12–22:18 | Давление масла | Снижение давления примерно до 3,5–3,6 бар |
| 22:18–22:28 | Температура подшипника | Повышение температуры примерно до 75–77 °C |
| 22:27–22:34 | Вибрация | Повышение уровня вибрации примерно до 3,4–3,9 мм/с |
| 22:34–22:39 | Частота вращения | Снижение оборотов примерно до 2960 об/мин |
| 22:40–22:49 | Активная мощность | Увеличение мощности примерно до 155 МВт |
| 22:40–22:49 | Расход воды | Увеличение расхода примерно до 1230 м³/ч |

Последние два отклонения связаны между собой и имитируют изменение режима нагрузки гидроагрегата. Они не обязательно свидетельствуют о неисправности оборудования.

**Важно:** указанные временные интервалы относятся к 26 октября 2026 года.

## Цель использования датасета

Основное назначение датасета — разработка и проверка ML-модели для автоматического обнаружения аномалий в показаниях датчиков гидроагрегата.

В рамках проекта предполагается:

1. Исследовать распределение показаний датчиков и выявить особенности нормального режима работы.
2. Выполнить предварительную обработку данных.
3. Обучить модель машинного обучения Isolation Forest для обнаружения выбросов.
4. Проверить способность модели обнаруживать искусственно внедрённые аномалии.
5. Сравнить результаты модели с методом обнаружения отклонений по заданным пороговым значениям.
6. Определять продолжительность аномальных эпизодов и временные границы отклонений.
7. Использовать обнаруженные аномалии для формирования диагностических заключений.

## Используемые технологии

В проекте предполагается использование следующих инструментов:

- **Python** — основной язык программирования.
- **Pandas** — обработка и анализ данных.
- **NumPy** — математические операции.
- **Scikit-learn** — реализация и обучение Isolation Forest.
- **Matplotlib / Plotly** — визуализация временных рядов и обнаруженных аномалий.

В дальнейшем результаты обнаружения аномалий могут передаваться локальной языковой модели через **Ollama** для формирования текстового диагностического заключения.

## Особенности и ограничения

- Датасет является полностью синтетическим и не содержит реальных производственных измерений.
- Аномалии внедрены искусственно для проверки алгоритмов обнаружения выбросов.
- В исходном CSV отсутствует отдельный столбец с метками нормальных и аномальных наблюдений.
- Для объективной оценки качества модели необходимо отдельно подготовить эталонную разметку аномальных интервалов.
- Наличие выброса не всегда означает неисправность: необходимо учитывать взаимосвязь параметров, продолжительность отклонения и текущий режим работы оборудования.
- Используемые значения являются демонстрационными и не должны рассматриваться как реальные нормативы эксплуатации гидроагрегатов.

## Ожидаемый результат

Результатом использования датасета должна стать система **TurbineLog**, способная автоматически анализировать показания датчиков, обнаруживать аномальные изменения, определять временные интервалы отклонений и формировать диагностические отчёты.

Датасет может использоваться для обучения, тестирования и сравнительной оценки алгоритмов обнаружения аномалий в задачах технической диагностики гидроэнергетического оборудования.
